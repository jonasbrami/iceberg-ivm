Write the query you would put after CREATE MATERIALIZED VIEW … AS. iceberg-ivm works out the rest and keeps the target table up to date.

A view's query and table can't change. To change them, create a new view.

What queries are supported?

One Iceberg source table, no joins or subqueries, and a date_trunc('<unit>', col) bucket that is selected and in the GROUP BY. Any aggregate works, including min_by, max_by, approx_percentile and count(DISTINCT …). LIMIT and window functions aren't supported.
